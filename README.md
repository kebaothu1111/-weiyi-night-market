# 味憶夜市：港都深夜食堂

一碗湯，喚回一段被遺忘的家鄉。 ・ Một bát canh gọi về miền quê đã quên.

在高雄港舊碼頭的午夜夜市，接手外婆「月嬤」的小吃攤。白天到漁港、菜市場、雜貨店採買，到工坊升級鍋具和店面；晚上開店招待客人，猜出「失味旅人」想念的家鄉味，把夜市的十五盞燈籠一盞盞點亮。

## 玩法

1. **地圖採買**：漁港買魚貨、菜市場買肉菜、雜貨店買鹽糖醬料。生鮮放太久會壞。
2. **工坊升級**：六種器具（炒鍋、平底鍋、湯鍋、烤架、油鍋、蒸籠）從「破舊」升到「傳說」，綠區更寬、指針更慢、熟得更快、品質更高；店面從鐵皮攤擴建成港都名店，座位更多。
3. **開店接待**：客人走進來坐下，點一下頭上有「!」的客人，照他的點單和特別要求（加蛋、加辣……）做菜。故事客人會說出回憶；大老闆、美食評論家要求高品質。
4. **備料＋火候**：照食譜順序點選食材，再玩各器具不同的小遊戲：狂點、翻面、按住控火、Audition 方向鍵、連撈三次、節奏拍點。按錯客人會更不耐煩。成品分 R / SR / SSR / UR，品質越高賣越貴。
5. **突發事件**：討債的流氓、午夜的白衣女子、整條街停電……你的選擇會影響金錢和口碑。
6. **娛樂城與借錢**：骰寶、拉霸、比大小；缺錢可以跟銀行借，或找地下錢莊的虎哥（利息很可怕）。
7. **每週日繳帳單**：店租、電費和月嬤的醫藥費。錢不夠，攤子就得收了。

五條街區、十五道台灣與東南亞料理，集滿 15 張料理卡迎接結局。
