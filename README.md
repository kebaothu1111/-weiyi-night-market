# 味憶夜市：港都深夜食堂

一碗湯，喚回一段被遺忘的家鄉。

在高雄港舊碼頭、只在農曆十五午夜營業的「月光夜市」裡，接手外婆「月嬤」的小吃攤。客人不會直接點菜，只會說一段回憶：猜出他想吃的料理、依序備料、抓準火候，幫十五位「失味旅人」找回家鄉味，把夜市的燈籠一盞盞點亮。

## 玩法

1. **早市採購**：用預算買今晚的食材包，放太久會壞。
2. **聽單猜菜**：從客人的回憶猜出料理。
3. **依序備料**：照正確順序點選 4 樣食材。
4. **火候判定**：指針停在綠區就是「完美」。
5. **上菜結算**：80 分以上拿到回憶碎片，集滿 3 片解鎖料理卡。

五條街區、十五道台灣與東南亞料理，集滿 15 張料理卡迎接結局。
